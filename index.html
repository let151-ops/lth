    사용 방법
    이 HTML 파일을 브라우저에서 열면 됩니다. 2~9단·랜덤 연습은 시간 제한 없이 풀고, ‘연습 마치기’를 누르면 결과가 나옵니다. 연습에서는 오답에 한 번 더 도전할 수 있고, 다시 맞힌 문제도 맞힌 개수에 포함됩니다. 오답 복습에는 한 번이라도 틀린 문제가 모입니다.

    실전모드
    시작 버튼을 누른 뒤 60초 동안 진행됩니다. 정답 확인 시간은 약 1초이며, 한 판의 점수는 최대 60점입니다. 다른 탭으로 이동해도 시간은 흐릅니다. 제한 시간을 끝까지 마치고 1문제 이상 맞힌 기록만 등록할 수 있습니다. 최고 기록은 이 브라우저에만 저장됩니다. 저장 공간을 사용할 수 없으면 최고 기록이 유지되지 않을 수 있습니다.

    Firebase 연결
    제공하신 프로젝트 ngtest-74fe3의 설정을 이미 넣었습니다. Analytics·Authentication·Realtime Database는 사용하지 않고, 기본 Cloud Firestore의 leaderboard 컬렉션을 사용합니다. 순위표를 처음 열거나 등록할 때만 Firebase SDK를 불러옵니다. 코드를 추가로 수정할 필요가 없습니다.

    불러오기·등록이 안 되나요?
    인터넷 연결과 Firestore 생성 여부, 아래 보안 규칙 게시 여부를 확인해 주세요. Realtime Database의 JSON 규칙과는 다릅니다. 네트워크나 브라우저 정책 때문에 파일로 열었을 때 연결이 막히면, 같은 HTML을 Firebase Hosting 같은 HTTPS 호스팅에 올려 사용하세요. API 키 제한·App Check 강제 적용·프로젝트 사용량 제한도 확인 대상입니다.

    공개 서비스 운영 시 주의
    웹용 Firebase 설정은 비밀키가 아닙니다. 이 앱은 로그인 없이 등록하므로, 보안 규칙을 적용해도 점수 조작이나 반복 등록을 완전히 막을 수 없습니다. 공개 대회용 검증 시스템이 아니며, 공개 배포 시 서버 측 검증·요청 제한·App Check 등을 별도로 검토해 주세요. App Check만으로 점수의 진위를 검증할 수는 없습니다. 게임에서는 이름·이메일·Analytics를 수집하지 않지만 Firebase 통신에 따른 정보 처리는 운영자가 확인해야 합니다.

    이 앱과 맞는 Firestore 보안 규칙 보기
    잘못된 기록은 Firebase 콘솔에서 관리자가 삭제할 수 있습니다. 게임 화면에서는 기록 수정·삭제를 제공하지 않습니다.
